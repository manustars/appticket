# appticket

> Provisional name.

A help desk that turns incoming e-mail into tickets, with an optional AI add-on that reads each mail
and proposes what to do with it. Extra features ship as add-ons: separate programs that the core
switches on and off.

**Status:** early development, nothing to install yet.
